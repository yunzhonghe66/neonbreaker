NEONBREAKER is an original neon arcade game: bounce the ball with the paddle, smash
every brick, and clear all 10 hand-designed neon grids. Normal, hard (2-hit) and
unbreakable steel bricks; bonus bricks worth 500; power-up capsules (multi-ball, wide
paddle, laser, slow-mo, extra life); combo scoring up to x5; particles, screen shake,
synthesised sound and a quiet bass pulse; persistent best score; pause, game over and
victory screens. Zero dependencies, zero network requests — all art is drawn in code
and all sound is synthesised with WebAudio.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Move with ← → or A D, or steer
with the mouse; Space or click launches the ball and fires the laser; P pauses;
M mutes.
